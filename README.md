This code is for a 0.96" SSD1306 OLED screen using a XIAO ESP32C3.
Code mainly focuses on low power consumption and burn in prevention to both extent battery life and OLED screen.
Intended package deployment through Arduino IDE
Must install esp32 by Espressif
Must install Adafruit SSD1306 by Adafruit
Must install Adafruit GFX Library by Adafruit
